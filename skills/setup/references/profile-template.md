# Job Hunt Profile layout

Create a Claude Doc titled **Job Hunt Profile** with these sections, in this order. Use tables where shown so later skills can read them reliably. Leave a section with a one-line "None yet" rather than deleting it.

1. **Contact** — name, email, phone, city/state or region, country, links to show (LinkedIn, portfolio, GitHub).
2. **Target roles** — field, titles, level range, stretch levels OK (yes/no).
3. **Job filters** — table: Filter | Value. Rows: work arrangement, travel, minimum pay (amount, currency, per year or per hour), country and locations / time zones, employment type, excluded company types, clearance, work authorization.
4. **Optional extras** — table: Extra | On/Off | Notes. Rows: identity/veteran boards (list them), status ranking boost, status on resume, scam and fit filters, repo verification (with repos folder path), second inbox (provider and URL).
5. **Job platforms** — table: Platform | Signed in on Chrome (yes/no) | Notes.
6. **Skills** — table: Category | Skill | Depth | Source. Depth is exactly one of: **work** (used in a job), **projects** (used in projects or volunteering), **coursework**, **familiar**.
7. **Experience** — one subsection per role, most recent first: Title — Employer (location) · start – end. Bullet list of confirmed accomplishments, each with its source. A separate "Verified metrics" line lists only numbers the user confirmed. "None yet" is fine for someone without work history.
8. **Projects** — table: Project | Link | Tools | What it does | Notable work | Source.
9. **Certifications and licenses** — name, issuer, month/year.
10. **Education** — degree or program, school, year.
11. **Military service / volunteer / domain experience** — as provided.
12. **Never claim** — skills, credentials and experience the user lacks, so resumes report them as gaps.
13. **Resume preferences** — style (classic, minimal, modern or compact; default classic), paper size (A4 or Letter), accent color override if any, font override if any, optional headline under the name, sections to include with their titles (for example "Clinical Experience"), page limit (one page).
14. **Links** — the Job Application Tracker link, filled in after it's created.

Add an as-of date chip in the byline and update it whenever the profile changes.
